# 임계값 분할 비교 실험

정답 마스크: 깨끗한 정상 차트 본문(32행 아래)에서 L ≥ 128인 밝은 구조. 노출·잡음을 바꿔도 같은 위치를 정답으로 쓴다.
IoU는 결과 흰색 영역과 정답의 교집합/합집합, FPR은 배경을 흰색으로 잘못 고른 비율, FNR은 구조를 놓친 비율이다.
Otsu는 팀 알고리즘이 아니라 같은 영상에 맞는 임계값이 무엇인지 보여주는 참고값이다(OpenCV, 본문 L).
