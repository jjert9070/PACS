# P01 가우시안 웹 연결

## 실행과 사용

기존 앱 실행/로그인을 유지한다. 저장소 루트에서 `uv sync --locked` 후
`uv run --locked --env-file .env streamlit run app.py`로 실행한다.

1. PNG/JPEG 파일 또는 합성 예시를 연다.
2. 왼쪽 가우시안 강도를 0~20 범위로 설정한다. 단위는 원본 픽셀 기준 표준편차 σ다.
3. 가우시안 적용을 누른다.
4. 중앙 왼쪽 원본과 오른쪽 처리 결과를 비교한다. 오른쪽에 알고리즘 ID/버전과 실제 σ가 나온다.

설정만 바꾼 경우 재계산하지 않으며 기존 결과의 실제 적용 강도와 변경 안내를 표시한다.
확대·이동·보기 초기화는 원본/결과에 같은 위치를 적용하며 이미 계산한 결과를 재사용한다.
강도 0도 명시적 적용이 필요하고 원본과 동일한 독립 복사 결과를 표시한다.
20 초과/음수 입력은 입력 위젯과 계산 함수에서 제한한다.

## 상태와 연결 경계

`gaussian_ui.py`가 설정 UI와 세션 결과를 담당한다. `app.py`는 기존
`render_viewer(processor=...)`에 처리 콜백을 전달한다. `viewer.py`의 선택/디코딩 후
`processing_controls` 훅으로 현재 원본을 기준으로 설정 UI를 그린다.
확대·이동·초기화 계산과 배치는 변경하지 않았다.

세션의 `viewer_processing_` 키에 결과와 적용 원본 ID, 알고리즘 ID/버전, 실제 강도를 기록한다.
적용할 때 이전 결과를 먼저 지우고 함수/크기/RGB 검증이 모두 성공한 뒤 새 결과를 게시한다.
실패하면 오류만 표시하고 이전 결과를 반환하지 않는다. 실패 후 보기 조작에도 오류가 유지되며,
다시 적용해 성공하면 해제된다. 다른 영상 또는 입력 모드로 변경하면 처리 상태와 강도를 초기화한다.
같은 이름의 다른 파일도 원본 해시로 구분한다. 로그아웃/만료는 기존 `clear_viewer`로 전부 정리한다.

C가 읽어 준 저장 결과는 적용 전 기존처럼 별도 출처 문구로 표시하며, 새 가우시안 실패 시에는
저장 결과로 자동 대체하지 않는다. 이번에 처리 결과의 C 저장 연결을 추가하지 않았다.
ROI 입력/통계, 감마/임계값 UI, DICOM은 후속 PR이다.

## 검증 기록과 제한

자동 검증 명령: `uv run --locked python -m unittest discover -v`.
기존 63개와 신규 웹 연결 7개를 포함해 총 70개가 통과했다.
입력은 기존 640×480 합성 예시와 같은 이름·다른 바이트의 생성 PNG다.
σ=0/1/2/3/20에서 정상 적용/설정 변경/항등/상한을 확인한다.
예외, 잘못된 크기, RGB가 아닌 결과와 None은 모의 처리 함수로 주입한다.
테스트는 원본 픽셀 불변, 결과 픽셀 기대값, 표시한 실제 설정, 재시도,
영상 교체, 로그아웃, 확대·이동·초기화 중 불필요한 재실행 방지를 검사한다.
기존 C의 케이스·로컬 저장 회귀 테스트도 유지한다.

브라우저 직접 검증은 **미완료**다. 로컬 127.0.0.1:8510에서 실제 app.main을 모의 로그인으로
띄워 파일 선택 전 화면까지 확인했으나, 확장 프로그램의 파일 접근 제한으로 Lenna 업로드가 실패했다.
Windows 선택창 확인 과정에서 컴퓨터 유즈가 현재 URL 확인 문제로 중단됐다.
정상·0·교체·실패 화면 캡처를 아직 첨부할 수 없으며, 자동 테스트를 수동 검증으로 표현하지 않는다.
검증용 모의 로그인/실패 주입 코드는 Git 무시 경로에만 있으며 운영 앱에는 추가하지 않았다.
실제 Firebase 로그인/권한/저장은 이번 브라우저 검증에서 시험하지 않았다.

수동 검증 시 Lenna.png와 σ=2로 적용 → σ=0 적용 → 다른 PNG 열기 →
실패 주입 후 오류와 기존 결과 제거 확인 → 정상 재시도 → 로그아웃을 수행하고
원본 파일명·해시·설정·결과 화면을 리뷰에 추가해야 한다.

통합 기준은 `intergrationOfBC`이며 이 PR도 해당 브랜치를 대상으로 한다.
기존 작업 폴더의 수정된 실험 산출물은 건드리지 않도록 별도 worktree에서 작업했다.
